# Amor · AI 剧情导演台

SillyTavern 第三方扩展。不是记忆剧情，而是**像导演一样控制 AI 怎么演**——用一组可视化旋钮控制每轮生成的节奏、镜头、叙事重点、角色主动性与推进速度，把它们压成一段「导演指令」注入到角色设定之前，让 AI 照着演。

## 能控制什么

- **剧情节奏**：平缓 / 日常 / 暧昧 / 紧张 / 冲突 / 高潮 / 余波（单选，再点取消=不指定）
- **镜头语言**：近景 / 中景 / 远景 / 人物特写 / 环境描写 / 动作描写（单选，可取消）
- **叙事重点**：人物心理 / 环境描写 / 对白 / 动作 四个滑条（0-10，条越满越侧重）
- **角色主动性**：用户角色 / AI 角色 / NPC 各自 低 / 中 / 高
- **剧情推进速度**：慢 ──●── 快（0-10）
- **自定义导演指令**：自由文本，如「本轮不要推进主线，只深化两人的关系」「开始制造冲突，但不要立刻解决」
- **自动导演**：开启后，每轮生成结束 AI 自动分析最近剧情、判断节奏/镜头/重点/主动性/速度，自动调好下方旋钮并写一句「导演特别指示」；旋钮和指令会实时显示在面板上
- **联动 Serendipity**：若已安装 Serendipity 记忆插件，导演会自动读取其剧情时间/时间线/人物/关系/世界状态/未完成伏笔/近期记忆，作为「剧情背景」喂给导演，让它看懂整个故事而不是只看最后 12 条
- **自动刷新**：点「立即导演」随时手动分析一次；或开启「定时自动刷新」按间隔（默认 60 秒）持续分析

## 剧情规划（1.3.0 新增）

「导演台」调的是**怎么写**，「剧情规划」决定**写什么**。面板顶部切到「剧情规划」页：

- 每轮回复结束后，规划师先**评估**上一个节拍实际发生了什么，再**重新规划**：当前场景、场景目标、当前冲突、下一个节拍（必须是一个具体的变化）、情绪方向、张力、本轮避免事项
- 事实来自 Serendipity（`getDirectorContext({purpose:'amor', tokenBudget, include})`，需 Serendipity ≥ 2.3.6；未安装时只用最近对话）；规划只是建议，**不会写入 Serendipity 的事实**
- 防空转：连续几轮没有变化会提示，并让下一个节拍引入外部事件或推进线索
- 保护玩家自主权：注入里明确禁止替 {{user}} 做重大决定，只能制造压力、提供机会、让别人行动
- 所有字段都能直接手改，改完立即生效；按「角色 + 聊天」分开存；删除消息 / 重新生成 / Swipe 时自动回滚到有效快照
- 两种模式：辅助（自动规划并注入）/ 手动（只分析不注入）；可设每几轮规划一次，可单独指定规划用的 API，失败时自动回退酒馆默认 API，规划失败不影响正文生成
- **剧情线（1.4.0 新增）**：规划师会把故事脉络归纳成主线 / 人物线 / 世界线，记录状态、重要度和进度，每个节拍尽量推进其中一条；重要的线久未推进会被提醒优先处理。剧情线只是 Amor 的解释，不写入 Serendipity；可在规划页手动增删改。
- **情绪弧线（1.5.0 新增）**：为情绪有明显变化的人物记录「当前情绪 → 变化 → 原因」，关注情绪**为什么**变化而不是数值；注入时提醒情绪变化要有原因和铺垫，不要突变。玩家角色只记录已表现出来的情绪，不规划其内心走向。可在规划页手动增删改，跟随快照回滚。
- **知识状态（1.6.0 新增）**：记录有剧情影响的信息差——某件事谁知情、谁只是怀疑、谁不知情，以及把握有多大。人物只有在剧情里亲眼看到、听到或被告知后才算知情，没有证据不假定；已知情的人不会被「忘掉」。注入里会写明：不知情的人物不能说出或表现出自己知道，怀疑者只能猜测试探。让玩家角色得知信息只能靠线索或他人行动。可在规划页手动编辑，跟随快照回滚。
- **伏笔导演（1.6.1 新增，需要 Serendipity 2.3.7+）**：伏笔本身仍记录在 Serendipity（Amor 不建第二套伏笔系统，也不能新增或宣布回收伏笔），Amor 只为每条未回收的伏笔安排「何时、怎样」处理：潜伏 / 暗示 / 铺垫 / 可回收四个阶段，以及怎样在场景里自然带出、什么条件下可以回收。注入里每轮最多带出一条伏笔，要求只能暗示、不能说破；回收需要玩家角色的选择时只提供契机。伏笔在 Serendipity 里被回收或删除后，这里自动同步。可在规划页手动调整，跟随快照回滚。
- **故事巡检（1.6.2 新增）**：纯规则检测，不调用模型，只提示、不改动任何数据。检查：剧情空转、节拍连续落空、张力过平或长期过高、重要剧情线久未推进、主线缺失、伏笔过多 / 时机成熟却没回收 / 铺垫后久未带出、情绪突变或缺少原因、信息差长期停滞、Serendipity 里待处理的一致性问题。结果显示在规划页「故事诊断」，同时把严重 / 注意级别的问题交给规划师，下一轮规划会尝试用剧情内的方式化解。
- **故事健康度（1.6.3 新增）**：由巡检结果推算的参考分（0–100），按推进 / 剧情线 / 伏笔 / 人物情绪 / 信息差 / 事实一致分项，并显示最近几次规划的走势。它只是帮你快速看出哪里需要留意，不是对故事好坏的评价；没接入 Serendipity 时，依赖它的分项不参与计算。
- 对外接口：`window.Amor.getStoryDirection({include})`，返回里含 `plotThreads`、`emotionalArcs`、`knowledgeState`、`foreshadowPlan`、`inspection`、`storyHealth`

## 怎么用

1. 酒馆 → 扩展 → 安装扩展 → 粘贴本仓库 Git 地址：`https://github.com/lit66731-star/Amor.git`。（酒馆所在机器需装有 git；Termux 用户先 `pkg install git`。）
2. 点扩展菜单里的「Amor」打开导演台。
3. 打开顶部「导演模式」开关，调好各项。
4. 直接发消息即可——每轮生成都会在角色设定之前注入导演指令，AI 照着节奏、镜头、重点来演。
5. 调好的一套可点「保存当前为预设」存成预设，随时一键载入。
6. 想完全托管就打开「自动导演」——每轮生成后 AI 自动分析剧情、调整旋钮并写一句导演指令，你只需看着它导。

## 工作原理

导演模式开启时，插件用 `setExtensionPrompt`（`BEFORE_PROMPT` 位置，即 prompt 最顶端、角色描述之前）注入一段「导演指令」，确保 AI 把它当作最高优先级指令严格遵守，而不是被角色设定或聊天记录盖过去。

> `auto_update` 已开启：酒馆检测到本仓库更新并拉取后，会自动刷新页面应用新版本。

- **1.4.0**：新增**剧情线（Plot Thread）**——规划师维护主线 / 人物线 / 世界线（状态、重要度、进度、最近推进），节拍对应到某条线，重要线久未推进会提醒；规划页可手动增删改；跟随快照回滚；`getStoryDirection` 返回 `plotThreads`。
- **1.5.0**：新增**情绪弧线（Emotional Arc）**——按人物记录当前情绪、变化历史与原因、可能的走向；注入里要求情绪变化有铺垫；规划页可手动编辑；`getStoryDirection` 返回 `emotionalArcs`。
- **1.6.0**：新增**知识状态（Knowledge State）**——按条记录谁知情 / 怀疑 / 不知情，防止人物说出不可能知道的信息；规划页可手动编辑；`getStoryDirection` 返回 `knowledgeState`。
- **1.6.1**：新增**伏笔导演（Foreshadow Director）**——按条规划 Serendipity 伏笔的铺垫与回收时机，注入里限制每轮最多带出一条、只暗示不说破；`getStoryDirection` 返回 `foreshadowPlan`。需要 Serendipity 2.3.7+。
