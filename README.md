# Amor · AI 剧情导演台

SillyTavern 第三方扩展。不是记忆剧情，而是**像导演一样控制 AI 怎么演**——用一组可视化旋钮控制每轮生成的节奏、镜头、叙事重点、角色主动性与推进速度，把它们压成一段「导演指令」注入到角色设定之前，让 AI 照着演。

## 能控制什么

- **剧情节奏**：平缓 / 日常 / 暧昧 / 紧张 / 冲突 / 高潮 / 余波（单选，再点取消=不指定）
- **镜头语言**：近景 / 中景 / 远景 / 人物特写 / 环境描写 / 动作描写（单选，可取消）
- **叙事重点**：人物心理 / 环境描写 / 对白 / 动作 四个滑条（0-10，条越满越侧重）
- **角色主动性**：用户角色 / AI 角色 / NPC 各自 低 / 中 / 高
- **剧情推进速度**：慢 ──●── 快（0-10）
- **自定义导演指令**：自由文本，如「本轮不要推进主线，只深化两人的关系」「开始制造冲突，但不要立刻解决」
- **自动导演**：开启后，每轮生成结束 AI 自动分析最近剧情、判断节奏/镜头/重点/主动性/速度，自动调好下方旋钮并写一句「导演特别指示」；旋钮和指令会实时显示在面板上
- **联动 Serendipity**：若已安装 Serendipity 记忆插件，导演会自动读取其剧情时间/时间线/人物/关系/世界状态/未完成伏笔/近期记忆，作为「剧情背景」喂给导演，让它看懂整个故事而不是只看最后 12 条
- **自动刷新**：点「立即导演」随时手动分析一次；或开启「定时自动刷新」按间隔（默认 60 秒）持续分析

## 剧情规划（1.3.0 新增）

「导演台」调的是**怎么写**，「剧情规划」决定**写什么**。面板顶部切到「剧情规划」页：

- 每轮回复结束后，规划师先**评估**上一个节拍实际发生了什么，再**重新规划**：当前场景、场景目标、当前冲突、下一个节拍（必须是一个具体的变化）、情绪方向、张力、本轮避免事项
- 事实来自 Serendipity（`getDirectorContext({purpose:'amor', tokenBudget, include})`，需 Serendipity ≥ 2.3.6；未安装时只用最近对话）；规划只是建议，**不会写入 Serendipity 的事实**
- 防空转：连续几轮没有变化会提示，并让下一个节拍引入外部事件或推进线索
- 保护玩家自主权：注入里明确禁止替 {{user}} 做重大决定，只能制造压力、提供机会、让别人行动
- 所有字段都能直接手改，改完立即生效；按「角色 + 聊天」分开存；删除消息 / 重新生成 / Swipe 时自动回滚到有效快照
- 两种模式：辅助（自动规划并注入）/ 手动（只分析不注入）；可设每几轮规划一次，可单独指定规划用的 API，失败时自动回退酒馆默认 API，规划失败不影响正文生成
- **剧情线（1.4.0 新增）**：规划师会把故事脉络归纳成主线 / 人物线 / 世界线，记录状态、重要度和进度，每个节拍尽量推进其中一条；重要的线久未推进会被提醒优先处理。剧情线只是 Amor 的解释，不写入 Serendipity；可在规划页手动增删改。
- **情绪弧线（1.5.0 新增）**：为情绪有明显变化的人物记录「当前情绪 → 变化 → 原因」，关注情绪**为什么**变化而不是数值；注入时提醒情绪变化要有原因和铺垫，不要突变。玩家角色只记录已表现出来的情绪，不规划其内心走向。可在规划页手动增删改，跟随快照回滚。
- **知识状态（1.6.0 新增）**：记录有剧情影响的信息差——某件事谁知情、谁只是怀疑、谁不知情，以及把握有多大。人物只有在剧情里亲眼看到、听到或被告知后才算知情，没有证据不假定；已知情的人不会被「忘掉」。注入里会写明：不知情的人物不能说出或表现出自己知道，怀疑者只能猜测试探。让玩家角色得知信息只能靠线索或他人行动。可在规划页手动编辑，跟随快照回滚。
- **伏笔导演（1.6.1 新增，需要 Serendipity 2.3.7+）**：伏笔本身仍记录在 Serendipity（Amor 不建第二套伏笔系统，也不能新增或宣布回收伏笔），Amor 只为每条未回收的伏笔安排「何时、怎样」处理：潜伏 / 暗示 / 铺垫 / 可回收四个阶段，以及怎样在场景里自然带出、什么条件下可以回收。注入里每轮最多带出一条伏笔，要求只能暗示、不能说破；回收需要玩家角色的选择时只提供契机。伏笔在 Serendipity 里被回收或删除后，这里自动同步。可在规划页手动调整，跟随快照回滚。
- **故事巡检（1.6.2 新增）**：纯规则检测，不调用模型，只提示、不改动任何数据。检查：剧情空转、节拍连续落空、张力过平或长期过高、重要剧情线久未推进、主线缺失、伏笔过多 / 时机成熟却没回收 / 铺垫后久未带出、情绪突变或缺少原因、信息差长期停滞、Serendipity 里待处理的一致性问题。结果显示在规划页「故事诊断」，同时把严重 / 注意级别的问题交给规划师，下一轮规划会尝试用剧情内的方式化解。
- **故事健康度（1.6.3 新增）**：由巡检结果推算的参考分（0–100），按推进 / 剧情线 / 伏笔 / 人物情绪 / 信息差 / 因果 / 事实一致分项，并显示最近几次规划的走势。它只是帮你快速看出哪里需要留意，不是对故事好坏的评价；没接入 Serendipity 时，依赖它的分项不参与计算。
- **因果链（1.7.0 新增）**：规划师为每个节拍写明「它由哪件已经发生的事引发」（节拍起因），并记录已经埋下、还没落地的后果（已埋下 / 该兑现 / 已兑现 / 已取消）。到了时机的后果会注入下一轮，让早先的行动真正产生分量；后果只落在世界与其他人物身上，不会替玩家角色做决定。巡检会提示「早已成熟却迟迟没落地」的后果、悬着太多后果、以及没有起因的节拍，健康度新增「因果」分项。可在规划页手动增删改，随快照回滚。
- **故事医生（1.7.1 新增）**：手动触发的深度诊断（调用一次模型）。结合巡检结果、剧情线、后果、伏笔、信息差和最近剧情，找出剧情空转 / 失衡的**根因**（目标缺失、冲突不足、场景目标已完成、话题耗尽、节奏失衡、因果断裂、信息差无处发力），并给出最多 4 条互不相同的**处方**（外部事件 / 推进秘密 / NPC 行动 / 转移场景 / 推进剧情线 / 兑现后果）。你可以采纳、忽略或稍后处理：采纳的处方变成有时限的「医嘱」（默认约 3 次规划内有效，最多同时 2 条），注入下一轮并交给规划师参考，也可以随时撤销。处方只制造压力、提供机会、让别人行动，不会替玩家角色做决定；状态良好时医生会如实说不需要处方。
- **选择引擎（1.7.2 新增）**：手动触发（调用一次模型），在需要决定的时刻为玩家角色列出 3–4 个走向不同的行动选项，并如实标出每个选项在推进、人物一致、风险、信息揭示、情绪变化上的程度，以及会触及哪条伏笔。选项只依据玩家角色自己知道的信息；不分优劣、不做推荐，**由你自己选**——可以一键填入输入框（有内容时会先确认）或复制。选项针对当时的剧情生成，对应消息被删除 / 改写后自动作废。
- **自动重规划（1.8.0 新增）**：规划本来按「每几轮规划一次」运行；现在如果巡检发现**严重问题**（如连续空转、重要剧情线长期不动），或规划的节拍**连续落空**，会不等周期、提前重新规划一次，并把触发原因告诉规划模型，要求换一个更容易自然发生的切入点。提前触发有冷却（至少隔 2 次规划），状态栏会显示原因；纯规则判断，不额外调用模型；可在「规划设置」里关闭（默认开启）。
- **自动导演模式（1.9.0 新增）**：规划模式新增第三档「自动导演」，用于纯 AI 剧情 / 无人值守。相比「辅助」：每轮都规划（不受「每几轮」限制）；规划模型会被要求每轮都让事态有实质变化、更主动地用事件和其他人物的行动推进；规划之后如果巡检仍有严重问题、且当前没有生效的医嘱，会**自动请故事医生会诊一次并采纳第一条处方**（冷却 4 次规划，医嘱仍有时限，可随时在「故事医生」里撤销）。**玩家角色的重大决定仍然不会被替做**。注意：自动导演只负责“规划和注入”，不会替你发送消息或自动续写——要无人值守地跑，请配合酒馆自带的自动续写 / 群聊自动模式。
- **内置导演风格（1.10.0 新增）**：导演台新增 9 种风格——均衡 / 慢热 / 电影感 / 高张力 / 恋爱 / 悬疑 / 权谋 / 沉郁 / 冒险。一键套用对应的节奏、镜头、叙事重点、角色主动性、推进速度，并给 AI 一句风格基调；套用后仍可逐项微调。**风格只影响怎么写，不改变任何事实与设定**。保存的预设也会记住所选风格。
- **故事大阶段 Story Arc（1.10.1 新增）**：规划师会判断整个故事走到了哪一幕（如「关系建立」→「冲突升级」），比剧情线和场景都更大更慢——不每轮重写，只在出现真正转折时才切换，已走过的阶段会留成一条链。当前阶段会作为背景方向注入，可手动修改，也可通过 `Amor.getStoryDirection` 的 `storyArc` 读取。
- **总览首页（1.10.2 新增）**：打开 Amor 先看到只读的「总览」——运行状态、故事阶段、当前场景（地点 / 在场人物 / 目标 / 冲突）、当前节拍与起因、情绪方向、张力、生效中的医嘱、故事健康度与待办，一眼看清 Amor 现在在做什么。
- **注入内容预览与手动覆盖（1.10.3 / 1.10.4）**：总览页可展开查看 Amor 下一条回复实际会注入的内容（导演台指令 + 剧情规划指令）及字数，并且**可以直接修改**。保存后用你写的版本替代自动生成（导演台指令全局生效，剧情规划指令按聊天保存），期间不再随设置或规划变化；点「恢复自动生成」或清空保存即回到自动。
- **规划历史与运行信息（1.11.0 新增）**：「剧情规划」页新增规划历史，逐轮列出安排的节拍、起因、实际发生的变化，以及每次规划的用时和输入输出字数，并可「回到这一轮」重新开始；总览页会显示上次规划的耗费，以及规划 / 会诊 / 生成选项最近一次失败的原因（不影响剧情生成）。
- **导出 / 导入备份（1.12.0 新增）**：「剧情规划」页底部可导出一份 JSON 备份（导演台设置与预设、规划设置、当前聊天的规划数据），换设备或重装时导入即可恢复。不含 API 地址和 Key，也不含 Serendipity 数据。
- **长聊瘦身与覆盖过期提醒（1.13.0 新增）**：规划提示词里，已完结的剧情线折成一行、暂停的只留要点、没有任何安排的潜伏伏笔合并成一行，聊得越久越不会膨胀（各类条目本来就有数量上限）。手动覆盖的指令如果已经过时（规划指令落后 3 轮以上，或导演台设置在你覆盖之后又改过），总览会提醒，并可展开查看当前自动版。
- **NSFW 一键开关（1.14.0 新增，1.14.2 可查看 / 修改）**：导演台顶部的独立开关，不需要先开导演模式。开启后每次生成都会把一段成人向描写许可放在聊天记录靠近末尾处发给模型（不回避、不跳过；仅限成年角色、双方愿意；不替用户角色做决定）。开关下方可展开查看完整提示词、直接改写、一键恢复默认，总览的「当前注入内容」里也能看到；会随备份导出 / 导入。
- 对外接口：`window.Amor.getStoryDirection({include})`，返回里含 `plotThreads`、`emotionalArcs`、`knowledgeState`、`foreshadowPlan`、`causalChains`、`doctorOrders`、`doctorReport`、`choices`、`inspection`、`storyHealth`

## 怎么用

1. 酒馆 → 扩展 → 安装扩展 → 粘贴本仓库 Git 地址：`https://github.com/lit66731-star/Amor.git`。（酒馆所在机器需装有 git；Termux 用户先 `pkg install git`。）
2. 点扩展菜单里的「Amor」打开导演台。
3. 打开顶部「导演模式」开关，调好各项。
4. 直接发消息即可——每轮生成都会在角色设定之前注入导演指令，AI 照着节奏、镜头、重点来演。
5. 调好的一套可点「保存当前为预设」存成预设，随时一键载入。
6. 想完全托管就打开「自动导演」——每轮生成后 AI 自动分析剧情、调整旋钮并写一句导演指令，你只需看着它导。

## 工作原理

导演模式开启时，插件用 `setExtensionPrompt`（`BEFORE_PROMPT` 位置，即 prompt 最顶端、角色描述之前）注入一段「导演指令」，确保 AI 把它当作最高优先级指令严格遵守，而不是被角色设定或聊天记录盖过去。

> `auto_update` 已开启：酒馆检测到本仓库更新并拉取后，会自动刷新页面应用新版本。

## 更新记录

- **1.3.0**：新增**剧情规划**页（场景 / 目标 / 冲突 / 节拍的评估与重规划、手动编辑、快照回滚、可选独立 API），与导演台旋钮并存、互不影响；注入使用独立键 `amor_story`。

- **1.3.2**：自动导演与剧情规划的模型调用改为排队执行，不再同时发出；自动导演读取 Serendipity 剧情背景时改为带 2500 token 预算（需 Serendipity ≥ 2.3.6，旧版不受限但会截断）。
- **1.3.3**：规划提示词里的格式示例改为中性描述，避免模型把示例当成剧情照抄。
- **1.3.4**：规划新增「无变化则跳过」的规则判断——距上次规划新增正文不足 150 字、且 Serendipity 事实指纹没变时，不调用模型（手动「重新规划」不受影响）；新增更新后自动刷新页面（ST 自动更新本插件后无需手动刷新）。
- **1.4.0**：新增**剧情线（Plot Thread）**——规划师维护主线 / 人物线 / 世界线（状态、重要度、进度、最近推进），节拍对应到某条线，重要线久未推进会提醒；规划页可手动增删改；跟随快照回滚；`getStoryDirection` 返回 `plotThreads`。
- **1.5.0**：新增**情绪弧线（Emotional Arc）**——按人物记录当前情绪、变化历史与原因、可能的走向；注入里要求情绪变化有铺垫；规划页可手动编辑；`getStoryDirection` 返回 `emotionalArcs`。
- **1.6.0**：新增**知识状态（Knowledge State）**——按条记录谁知情 / 怀疑 / 不知情，防止人物说出不可能知道的信息；规划页可手动编辑；`getStoryDirection` 返回 `knowledgeState`。
- **1.6.1**：新增**伏笔导演（Foreshadow Director）**——按条规划 Serendipity 伏笔的铺垫与回收时机，注入里限制每轮最多带出一条、只暗示不说破；`getStoryDirection` 返回 `foreshadowPlan`。需要 Serendipity 2.3.7+。
